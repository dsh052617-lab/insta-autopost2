# 인스타 대체 카드 만들기 (오후 예약 작업)

낮 12시 17분 '인스타 대체 카드 (오후)' 작업이 이 문서를 처음부터 끝까지 읽고 그대로 따른다.
원고 형식·출처 규칙·이슈 만들기·확인·픽스 동기화는 `docs/insta_step3.md`의 4)~8)과 같다(먼저 그 문서도 읽는다).
이 문서가 예약 작업 지시문의 안전 규칙과 다르면 지시문을 우선한다.

## 안전 규칙
이슈를 만들고 확인하고 실패한 내 원고 이슈를 닫는 것 외에, 어떤 이슈에도 명령 댓글(승인·지금 게시·취소·날짜·수정)을 달지 않는다.

## 1) 할 일 찾기
TODAY = `TZ=Asia/Seoul date +%Y-%m-%d`. clone 폴더의 `data/skip/<TODAY>-economy.txt`, `data/skip/<TODAY>-ai.txt`를 본다.
첫 줄이 정확히 `pending-fallback`인 파일의 주제만 처리한다(economy 먼저, 그다음 ai). 둘 다 없으면 메시지 없이 끝낸다.

각 주제마다 먼저 중복 확인(`docs/insta_step3.md` 1)과 같은 방법, 단 skip 파일은 보지 않는다):
오늘 날짜·그 주제의 열린 초안, 오늘 게시된 초안, 또는 열린 "직접:" 이슈가 있으면 만들지 않고 표시 파일 첫 줄을 `done: 이미 초안 있음`으로 바꿔 push한다.

## 1-S) 준비해 둔 카드부터 (토큰 절약)
새로 만들기 전에 `data/stock/`에서 `<주제>-*.json` 파일(README·used 폴더 제외)을 이름순으로 찾는다.
- 있으면 첫 파일을 읽어 `"date"`를 TODAY로 바꾼 JSON을 3)의 형식 그대로 이슈 본문(```json 블록)에 넣고,
  제목은 kind에 맞게 `직접: [M/D 경제·역사] <사건 이름>` / `직접: [M/D 경제·용어] <용어>` / `직접: [M/D AI·비교] …`로 만든다.
  (경제는 용어↔경제사 번갈아 규칙보다 준비해 둔 카드를 먼저 쓴다.)
- 4)대로 확인한다. 성공하든 거절되든 그 파일은 `git mv data/stock/<파일> data/stock/used/`로 옮겨 push한다(같은 카드를 다시 시도하지 않는다).
- 성공하면 이 주제는 끝(4)의 표시 정리 → 5)). 거절되면(출처 페이지가 사라졌거나 이미 쓴 출처와 겹침 등) 그 이슈를 닫고 아래 2-E)/2-A)로 새로 만든다.
- 파일이 없으면 바로 2-E)/2-A)로.

## 2-E) 경제(economy) — 용어 카드와 경제사 카드를 번갈아 (게시 20:00)
`data/history.json`과 draft 이슈(열린 것·게시된 것)에서 kind가 "term" 또는 "history"인 가장 최근 글을 찾아,
그것이 "term"이면 경제사 카드, "history"이거나 없으면 용어 카드를 만든다.

**용어 카드** (kind "term")
- 최근 7일 경제 뉴스에 실제로 나온 용어 중 대학생·사회초년생이 뉴스를 이해하는 데 꼭 필요한 것 1개
  (예: 기준금리, 가산금리, DSR, 국고채 금리, 근원물가, 경상수지, 양적긴축).
  픽스 데이터(ArtifactData, url "https://claude.ai/artifact/BKu81S9yMm9Z8zU9wyqhFZ", collection "news", doc_id "economy")의 오늘 브리핑 items를 참고한다.
  이미 다룬 용어(history.json·이슈 제목)는 고르지 않는다.
- 출처: 그 용어를 쓰거나 설명한 최근 7일 이내 허용 출처 기사 2개 이상(서로 다른 언론사), 또는 공식 기관 자료 1개 이상 + 기사 1개.
  이미 게시한 글에서 쓴 기사 주소(history.json의 urls)는 다시 쓰지 않는다(프로그램이 '겹침'으로 거절한다).
- 구성: cover_kicker "오늘의 경제 용어", cover_title 첫 줄 = 용어, 둘째 줄 = 짧은 훅.
  slides: ① 한 줄 뜻(쉬운 말) ② 어떻게 움직이나·왜 중요한가 ③ 최근 뉴스 속 이 용어(출처에 있는 사실·숫자만) ④ 나에게 의미·확인할 점.
- 이슈 제목: `직접: [M/D 경제·용어] <용어>`

**경제사 카드** (kind "history")
- 경제 위기·전환점 이야기 1개를 쉽고 흥미롭게, 사실은 정확하게
  (예: 1997 외환위기, 2008 글로벌 금융위기, 1985 플라자 합의, 2000 닷컴 버블, 1970년대 오일쇼크, 1979 볼커 쇼크, 2020 코로나 경제 충격).
  요즘 뉴스와 이어지는 것을 우선한다. 이미 다룬 사건은 다시 쓰지 않는다.
- 출처: 7일 규칙 대신, 공식 기관 자료(한국은행·KDI·IMF·Fed·BIS 등 허용 목록의 보고서·해설 페이지)나 허용 언론의 해설·기념 기사 2개 이상.
  각 출처의 게시일을 확인하고, 사실·숫자는 모두 그 본문에 있는 것만(기억으로 숫자를 쓰지 않는다).
  표지 제목의 연도 같은 숫자도 출처 본문에 그 표기 그대로 있어야 한다.
- 구성: cover_kicker "경제사 한 장면", slides: ① 무슨 일이 있었나 ② 왜 일어났나 ③ 어떻게 수습됐나·남긴 것 ④ 지금 우리에게 주는 교훈(요즘 뉴스와 연결).
  재미는 비유와 질문으로, 과장·자극적 표현 금지.
- 이슈 제목: `직접: [M/D 경제·역사] <사건 이름>`

마땅한 소재·출처를 못 찾으면 다른 종류(용어↔경제사)를 시도하고, 그것도 안 되면 표시 파일 첫 줄을 `done: 건너뜀 <이유>`로 바꿔 push하고
"📮 인스타 초안 · 오늘 경제 카드는 쉬어요 (<한 줄 이유>)" 메시지.
category는 금리·통화/물가·생활비/부동산·주거/금융·투자제도/고용·소득/무역·환율/재정·세금/산업·기업/글로벌 경제 중 하나.

## 2-A) AI(ai) — AI 모델 비교 카드, 최대 일주일에 1번 (게시 21:00)
- 횟수 제한: `data/history.json`과 draft 이슈에서 kind가 "compare"인 글의 date가 TODAY 포함 최근 7일 안에 있으면 만들지 않고 건너뛴다(프로그램도 거절한다).
- `docs/rules/compare.md`를 처음부터 끝까지 읽고 그대로 따른다(모델 고르는 기준, "모델명 (서비스명)" 표기, 평가 기관, 출처, 공정성, 구성, JSON 형식, 이슈 제목).
- 참고: Artificial Analysis 모델 페이지(artificialanalysis.ai/models/<모델>)에서 검증 프로그램이 글자로 읽을 수 있는 건 보통
  Intelligence Index 점수, 문제당 걸린 시간, API 가격뿐이다. 다섯 축을 같은 기관 원문으로 모두 확인할 수 없으면 오각형 대신
  막대그래프(종합 점수, 문제당 시간 등)로 만든다. 점수가 어떤 설정(max·high 등)에서 나온 것인지 그래프 note에 쓰고,
  요금제마다 쓸 수 있는 생각 단계가 다르면(예: ChatGPT Plus는 Extra High 없음) 공식 도움말로 확인해 카드에 밝힌다.
  요금제 포함 여부는 claude.com/pricing, help.openai.com, blog.google 같은 공식 페이지로 확인한다(공식 출처가 1건 이상 있어야 출처 조건을 통과한다).
- 건너뛰기: 주 1회 제한에 걸리거나 소재·출처를 못 찾으면 표시 파일 첫 줄을 `done: 건너뜀 <이유>`로 바꿔 push하고
  "📮 인스타 초안 · 오늘은 AI 카드를 쉬어요 (<한 줄 이유>)" 메시지.
- category는 기술·모델. needs_disclaimer는 true.

## 4) 확인 후 표시 정리
`docs/insta_step3.md` 7)대로 확인한다(다시 만들기 최대 2번, "겹쳐서" 거절이면 다른 출처·다른 소재로).
끝나면 표시 파일 첫 줄을 `done: #<번호>`(실패면 `done: 실패 <이유>`)로 바꾸고
`git add`, `git commit -m "fallback done: <TODAY> <주제>"`, `git pull --rebase -q`, `git push -q`.

## 5) 픽스 동기화 → 결과 메시지
`docs/insta_step3.md` 8)과 같다. 메시지는 만든 카드마다

"픽스 뉴스 탭에서 승인·수정할 수 있어요 · <이슈 링크>". 검증 실패로 끝났으면 그 사실도 한 줄로.
