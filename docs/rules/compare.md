# AI 모델 비교 카드 규칙 (kind: "compare")

아침 AI 작업이 '주요 AI 이슈가 없는 날'에만, **최대 일주일에 1번** 만든다. (횟수 제한·건너뛰기는 예약 작업 지침에 있음)

## 1. 어떤 모델을 비교하나
- **유료 이용자 중 일반 학생·직장인이 가장 많이 쓰는 모델**을 비교한다.
  - 기준: 개인용 기본 유료 요금제(월 2~3만 원대, 예: ChatGPT Plus · Claude Pro · Google AI Pro(Gemini))에서 **기본으로 쓰는 대표 모델**. 최고가 요금제(월 20만 원대 이상)에서만 쓸 수 있는 모델은 넣지 않는다.
  - 서비스 고르기: 국내외 이용자 수가 큰 개인용 AI 서비스 2~3개. 이용자 수·순위는 허용 출처(언론·조사기관)에 나온 것만 근거로 쓰고, 없으면 "대표적인 유료 AI 서비스"라고만 쓴다(근거 없는 '가장 많이 쓰는' 표현 금지).
  - 각 모델이 그 요금제에 포함된다는 사실은 회사 공식 요금제·도움말 페이지로 확인한다(claims에 근거).
- 직전 비교와 같은 조합이면, 그 사이 어느 서비스든 기본 모델이 바뀌었을 때만 다시 비교한다(무엇이 바뀌었는지를 중심으로).

## 2. 표기
- 모델은 항상 **"모델명 (서비스명)"** 으로 쓴다. 예: `Opus 5.5 (Claude)`, `GPT-5.5 (ChatGPT)`, `Gemini 3.5 Pro (Gemini)` — 모델명·서비스명은 공식 표기 그대로(위 예시의 버전 숫자는 형식 예시일 뿐, 실제 이름은 출처에서 확인).
- 그래프 label도 같은 형식(20자 이내).

## 3. 평가 기준 (오각형)
- 회사가 스스로 낸 점수가 아니라 **독립 평가 기관이 같은 조건으로 직접 시험한 점수**만 쓴다.
- 다섯 축은 고정, 다섯 값 모두 **같은 평가 기관 한 곳**(우선순위: Artificial Analysis → Epoch AI)에서 가져온다:
  1. 종합 — Artificial Analysis Intelligence Index
  2. 과학 추론 — GPQA Diamond
  3. 난제 — Humanity's Last Exam
  4. 코딩 — 그 기관의 코딩 시험(Artificial Analysis Coding Index 또는 Terminal-Bench Hard / Epoch AI면 SWE-bench Verified)
  5. 에이전트 — 그 기관의 에이전트·도구 사용 시험(Artificial Analysis Agentic Index, τ²-Bench 등. Elo 점수는 쓰지 않음)
- 모든 값은 0~100(%·지수). 한 축이라도 비교 모델 모두의 값을 같은 기관에서 못 찾으면 그 모델을 빼거나(최소 2개) 오각형 대신 막대그래프로 바꾼다. 기관을 섞지 않는다.

## 4. 출처
- 평가 기관 페이지(점수 근거) + 각 회사 공식 요금제·모델 페이지(요금제 포함 여부·가격·출시일 근거) + 필요하면 허용 언론 기사.
- 숫자는 모두 출처 본문 그대로(기억으로 쓰지 않음). 점수 하나하나 claims에 근거 구절(프로그램이 그래프 숫자도 원문 검사).

## 5. 공정성
- 특정 회사에 유리하게 쓰지 않는다. Anthropic의 Claude가 대상이어도 똑같은 기준.
- '최고 모델' 결론 대신 '이런 용도엔 이런 차이'. 홍보 문구 옮기지 않음.
- 마지막 장에 "시험 점수는 한 단면이고 실제 사용감과 다를 수 있다" 한 줄.
- 표지에는 프로그램이 자동으로 "유료 프로모션을 일절 받지 않은 정보 공유 게시물이에요" 문구를 넣는다(따로 쓰지 않음). 실제로 어떤 대가도 받지 않은 글만 이 종류로 만든다.

## 6. 구성 (4장)
1. 무엇을 비교하나 — 서비스·요금제·기본 모델, 어느 기관의 시험인지 (terms에 GPQA·HLE 등 풀이)
2. **오각형 그래프 카드**
3. 가격·이용 방법·특징 차이 (같은 조건의 가격 2개 이상이면 막대그래프 가능)
4. 나에게 맞는 선택 기준·확인할 점 + 점수의 한계 한 줄

## 7. JSON 형식
- 오각형 슬라이드:
  `"chart":{"type":"radar","title":"Artificial Analysis 독립 평가 점수","unit":"","note":"<기관 · 확인 날짜, 40자 이내>","axes":["종합","과학 추론","난제","코딩","에이전트"],"items":[{"label":"Opus 5.5 (Claude)","values":["..","..","..","..",".."]}]}`
  — values는 원문 표기 그대로의 숫자 문자열 5개, items 2~3개, heading 짧게, points·terms는 비움.
- 막대그래프 슬라이드: `"chart":{"title":"..","unit":"..","note":"..","items":[{"label":"..","value":".."}]}` — items 2~4개, 같은 조건 숫자만, points 1개.
- 원고 JSON: `"kind":"compare"`, `needs_disclaimer: true`, 이슈 제목 `직접: [M/D AI·비교] <cover_title 한 줄>`.
