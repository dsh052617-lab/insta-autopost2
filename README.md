# 인스타 카드뉴스 자동 업로드

AI·경제 뉴스를 모아서 Claude가 카드뉴스를 만들고, 검토하고 승인하면 인스타그램에 자동으로 올려주는 프로그램이에요.
GitHub Actions에서 무료로 돌아가서 컴퓨터를 꺼둬도 괜찮아요.

## 일주일 흐름

| 언제 (한국시간) | 무슨 일 |
|---|---|
| 월·수 저녁 8시 20분쯤 | 다음 날 올릴 초안 생성 → GitHub 이슈로 알림 (화요일 **AI** 1개, 목요일 **경제** 1개) |
| 그 사이 언제든 | 이슈에 댓글로 `승인` / `수정: …` / `지금 게시` / `취소` |
| 화·목 저녁 8시 | 승인된 초안을 인스타에 게시 → 이슈에 게시물 링크 남기고 닫기 |
| 매주 일요일 | 인스타 토큰 만료일 자동 연장 |

**승인하지 않은 초안, 출처 검증을 통과하지 못한 초안은 절대 올라가지 않아요.**

## 출처 규칙 (코드로 강제)

1. **신뢰 출처만 사용**: `config.yaml`의 `sources`에 등록한 정부·중앙은행·국제기구·기업 공식 발표와 주요 언론(통신사, 종합일간지, 경제지, 방송, IT 전문지 등 50여 곳) 기사만 써요. 목록 밖 사이트로 연결되는 기사는 자동으로 빠져요.
2. **원문 직접 확보**: 기사 페이지에서 본문을 실제로 가져온 경우에만 사용해요. 요약문만 있는 기사는 쓰지 않아요.
3. **교차 확인**: 공식 발표 1건 이상, 또는 서로 다른 언론사 2곳 이상이 다룬 내용만 게시물로 만들어요. 다른 매체가 연합뉴스·뉴시스·뉴스1 기사를 그대로 실은 경우는 같은 1곳으로 세요. 출처가 부족하면 신뢰 출처 목록 안에서만 웹 검색해 같은 사건을 다룬 기사를 자동으로 보충해요(Console에서 웹 검색이 켜져 있어야 함).
4. **근거 대조**: 카드에 쓴 사실마다 Claude가 원문 구절을 근거로 달고, 프로그램이 그 구절이 원문에 글자 그대로 있는지 확인해요.
5. **숫자 대조**: 카드·캡션의 숫자가 원문에 없으면 실패 처리해요.
6. 검증에 실패하면 자동으로 두 번 다시 쓰고, 그래도 실패하면 이슈 제목에 `❌ 출처 검증 실패`가 붙고 `승인`·`지금 게시`가 막혀요.

이슈 본문에서 '카드에 쓴 사실 ↔ 근거 원문 링크' 표를 확인할 수 있어요. 숫자가 아닌 해석이나 표현은 코드로 완전히 확인할 수 없으니, 승인 전에 표의 링크를 한 번씩 열어보는 걸 권해요.

## 무엇을 고르나요 (자동 업로드)

- **최근 7일 안에 나온 기사만** 써요 (코드로 제한).
- 그중 **이번 주 가장 비중 있는 이슈**(여러 매체·기관이 다룬 것, 실제 변화를 만든 것)를 고르고,
  **취준생과 일반 국민에게 실제로 도움이 되는 정보**(일자리·채용, 금리·대출, 물가·생활비, 세금·지원제도, 정책·규제 변화, AI가 일자리·경제에 미치는 영향)를 우선해요.
- **새 AI 도구·제품 출시 소식은 최후의 선택**이에요. 기준에 맞는 다른 이슈가 하나도 없을 때만 고르고, 그 경우 이슈의 '고른 이유'에 밝혀둬요.
- 자극적 사건·갈등 위주 기사, 루머·전망만 있는 기사, 주가 단신, 광고성 기사는 빼요.

## 투자 안내 문구 (필요할 때만)

특정 기업·종목·코인·금융상품이 나오거나 투자 판단으로 오해될 수 있는 글에만 **표지 하단과 캡션**에 아래 문구가 자동으로 붙어요. Claude의 판단과 투자 관련 단어(주가, 종목, 매수, 코인 등) 검사 중 하나라도 해당하면 붙어요.
> ※ 특정 기업·상품에 대한 투자 권유가 아닌 정보 제공 목적의 글이에요. 투자 판단은 본인의 책임이에요.

## 카드 구성 (5~6장)

표지 → 본문 3~4장(카드마다 한 줄 요점 2~3개, 핵심 단어만 굵게, **하단에 전문용어 한 줄 풀이**) → 한 줄 정리 + 출처

## 내 주제로 카드뉴스 만들기

같은 디자인·출처 규칙·검증으로, 원하는 주제를 카드뉴스로 만들어요.

**방법 1 (폰에서 쉬움)**: 저장소 → Issues → New issue → 제목을 `주제: 청년도약계좌 바뀐 점`처럼 쓰고 만들기.
본문에 원하는 관점("취준생 입장에서")이나 참고할 신뢰 출처 링크를 적어도 돼요.
3~5분 뒤 그 이슈가 초안으로 바뀌고, `승인`이라고 달면 **바로** 게시돼요.

**방법 2**: Actions → **5. 내 주제로 만들기** → Run workflow → 주제 입력.

- 자료는 `config.yaml`의 **신뢰 출처 목록 안에서만** 웹 검색해서 찾아요. 그 밖의 사이트는 링크를 줘도 쓰지 않아요.
- 출처 조건(공식 발표 1건 또는 언론사 2곳)을 못 채우면 만들지 않고 이유를 댓글로 알려줘요.
- 웹 검색은 Claude Console 조직 설정에서 web search 사용이 허용돼 있어야 해요. 처음 실행이 검색 오류로 실패하면 Console 설정에서 켜주세요.

## 처음 한 번만 하는 설정

### 1. 인스타 계정을 프로페셔널 계정으로 바꾸기 (폰)
인스타 → 설정 → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → **크리에이터** 선택.

### 2. GitHub 저장소 만들기
1. github.com 가입 → 오른쪽 위 **+** → **New repository**
2. 이름: `insta-autopost`, **Public** 선택 → **Create repository**
   - Public이어야 인스타가 카드 이미지를 가져갈 수 있어요. 키는 아래 Secrets에 비공개로 저장되니 공개되지 않아요.
3. 이 폴더의 파일을 전부 올리기 (저장소 화면의 **uploading an existing file** → 파일 끌어다 놓기).
   `.github` 폴더도 꼭 함께 올려야 해요.

### 3. Claude API 키
1. https://platform.claude.com 가입
2. **Billing**에서 크레딧 소액 충전 (화·목 주 2회면 한 달 1,000원 안팎)
3. **API Keys** → **Create Key** → 복사해서 잠깐 메모

### 4. 인스타 토큰 발급 (PC에서, 만료 없는 토큰)
최근 만든 Meta 앱은 'Unified login(통합 로그인)' 방식만 쓸 수 있어요. 비즈니스 포트폴리오(무료)가 필요하고, 대신 **만료 없는 토큰**을 받아요.

1. https://developers.facebook.com → **My Apps** → **Create App** → 이용 사례 **'Instagram에서 메시지 및 콘텐츠 관리'** 선택 → 앱 만들기
2. 대시보드 → 이용 사례 맞춤 설정 → **API setup with Unified login** → **+ 비즈니스 포트폴리오**로 새 포트폴리오를 만들어 연결
3. 같은 화면의 **권한 및 기능**에서 `instagram_basic`, `instagram_content_publish`가 있는지 확인 (광고 권한은 필요 없음)
4. https://business.facebook.com/settings (비즈니스 설정) → **계정 → Instagram 계정** → 추가 → 내 인스타 계정으로 로그인해 연결
5. **사용자 → 시스템 사용자** → 추가 (이름: insta-autopost, 역할: 관리자)
6. 만든 시스템 사용자 → **자산 할당**: 앱(AGI시대 경제)과 Instagram 계정을 전체 권한으로 할당
7. **새 토큰 생성** → 앱 선택 → 만료: **사용 안 함** → 권한 `instagram_basic`, `instagram_content_publish` 체크 → 생성 → 토큰 복사 (EAA로 시작)

> 내 계정에만 게시하는 용도라 앱 심사(App Review)나 앱 게시는 필요 없어요.
> 인스타 계정 ID는 프로그램이 토큰으로 자동으로 찾아요. 못 찾으면 실행 기록에 안내가 나오니 그때 `IG_USER_ID`를 추가하면 돼요.

### 5. GitHub에 비밀값 넣기
저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

| 이름 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | 3번에서 만든 Claude API 키 |
| `IG_ACCESS_TOKEN` | 4번에서 만든 인스타 토큰 |
| `GH_PAT` | (예전 IGAA 토큰을 쓸 때만) 토큰 자동 연장용 — 만료 없는 EAA 토큰이면 필요 없음 |

**GH_PAT 만들기:** GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
→ Repository access: **Only select repositories** → `insta-autopost`
→ Permissions → Repository permissions → **Secrets: Read and write** → Expiration: **Custom → Claude 키와 같은 날짜(1년 뒤)** → 생성 후 복사.
(없으면 60일마다 4번을 다시 해서 `IG_ACCESS_TOKEN`을 바꿔줘야 해요.)

### 6. 계정 정보 확인
`config.yaml`에 인스타 아이디(`@agi.economy.kr`)와 프로젝트 이름(`AGI시대 경제`)이 이미 들어 있어요. 바꿀 일이 생기면 저장소에서 `config.yaml` → 연필 아이콘 → 수정 → **Commit changes**.

### 7. 첫 테스트
저장소 → **Actions** 탭 → (처음이면 활성화 버튼 클릭) → **1. 초안 만들기** → **Run workflow**.
2~3분 뒤 **Issues** 탭에 초안이 생겨요. 확인하고 `승인`, 바로 올려보고 싶으면 `지금 게시`라고 댓글을 달면 돼요.

> GitHub 앱을 깔고 알림을 켜두면 폰으로 초안 알림을 받고 댓글로 승인까지 할 수 있어요.

## 댓글 명령어

| 댓글 | 결과 |
|---|---|
| `승인` | 예정 시각에 게시 |
| `수정: 제목 덜 자극적으로, 2번 카드 더 쉽게` | 원문을 다시 가져와 새 버전 작성 + 재검증 후 이슈 본문 교체 (다시 `승인` 필요) |

## 바꾸고 싶을 때

**게시 시각·요일**: `config.yaml`의 `post_time`, `days`와 함께 워크플로 cron도 바꿔야 해요. cron은 **UTC 기준**(한국시간 − 9시간)이에요.

| 파일 | 지금 값 | 뜻 |
|---|---|---|
| `.github/workflows/publish.yml` | `35 10 * * 2,4` | 화·목 19:35 시작 → 20:00까지 기다렸다 게시 |
| `.github/workflows/draft.yml` | `23 11 * * 1,3` | 월·수 20:23 초안 생성 |

예) 수·금 21시로 바꾸려면 → `post_time: "21:00"`, `days: {wednesday: ai, friday: economy}`, publish cron `35 11 * * 3,5`, draft cron `23 11 * * 2,4`.

**모델**: `config.yaml`의 `claude.model`을 `claude-sonnet-5-5`로 바꾸면 글쓰기 비용이 절반이에요. '내 주제'의 자료 검색은 가장 저렴한 `research_model`(Haiku)이 맡아요.

**신뢰 출처 추가**: `config.yaml`의 `sources`에 `도메인: { name: "이름", tier: official 또는 press }`를 추가하세요.

## 문제 해결

- **초안이 안 만들어져요** → Actions 탭에서 빨간 X를 눌러 로그 확인. `피드 실패`가 많으면 `config.yaml`의 피드 주소를 바꿔주세요.
- **'초안 없음 — 출처 조건 미충족' 이슈가 생겼어요** → 최근 며칠 동안 교차 확인되는 기사가 없었다는 뜻이에요. `lookback_days`를 늘리거나 신뢰할 만한 피드를 추가해 주세요.
- **게시 실패: 토큰·권한 오류** → 4번의 6~7단계(자산 할당, 권한 체크)를 다시 확인하고 새 토큰으로 `IG_ACCESS_TOKEN`을 바꿔주세요.
- **게시 실패: 이미지 처리 오류** → 저장소가 Public인지 확인해주세요.
- **예약이 멈췄어요** → GitHub은 활동이 60일 없는 공개 저장소의 예약 실행을 멈춰요. 이 프로그램은 매주 커밋을 남겨서 보통 문제없지만, 멈췄다면 Actions 탭에서 다시 켜주세요.

## 파일 구성

```
config.yaml              설정 (계정, 일정, 모델, 뉴스 출처, 색상)
src/draft.py             신뢰 출처 수집 → 기사 선택 → 원고 작성 → 출처 검증 → 카드 이미지 → 검토 이슈
src/verify.py            출처 규칙·근거 구절·숫자 대조
src/custom.py            내 주제 카드뉴스 (신뢰 출처 안 웹 검색)
src/handle_comment.py    이슈 댓글(승인/수정/지금 게시/취소) 처리
src/publish.py           인스타 캐러셀 게시
src/render.py            카드 디자인 (1080×1350)
src/writer.py            Claude 프롬프트
drafts/                  날짜별 초안 이미지와 원고
data/history.json        게시 기록 (같은 기사 중복 방지)
```

## 문제가 생겼을 때

- **0. 설정 점검** (Actions → 0. 설정 점검 → Run workflow): Claude 키·모델, 폰트, 뉴스 피드, 이미지 주소, 인스타 토큰·계정, GitHub 권한을 한 번에 확인하고 결과를 이슈로 남겨요. 비밀값은 결과에 적히지 않아요. `search`를 체크하면 Claude 웹 검색까지 확인해요(약 10~20원).
- **자동 실행이 실패하면** `[오류] …` 이슈가 자동으로 생기고(빨간 `error` 라벨), 오류 내용과 실행 기록 링크가 적혀요. 초안·게시 이슈에서 난 오류는 그 이슈에 댓글로 달려요.
- **예비 실행:** GitHub 예약 실행은 가끔 늦거나 빠져서, 초안은 게시 당일 아침 9시 23분, 게시는 저녁 8시 12분에 한 번 더 확인해요. 이미 처리된 회차는 건너뛰어요.
- Claude 응답이 형식에 맞지 않거나 잘리면 자동으로 다시 요청하고(최대 5번), 과부하·요청 한도 오류는 기다렸다 다시 시도해요.

## 직접 만든 원고 등록 (Claude API 요금 없음)

Claude 대화창에서 원고(JSON)를 받아 이슈로 등록하면, 출처 원문 대조·카드 그리기·게시를 Claude API 없이 처리해요.

1. Claude 대화창에서 "○○ 주제로 카드뉴스 원고 만들어줘"라고 요청 → 원고 링크나 ```json 블록을 받음
2. Issues → New issue → 제목 `직접: 주제 이름`, 본문에 원고(JSON) 붙여 넣기 → Create
3. 1~2분 뒤 같은 이슈에 카드와 검증 결과가 올라옴 → `승인`하면 바로 게시

- 출처 검증 규칙은 똑같아요: 신뢰 출처만, 공식 1건 또는 언론사 2곳, 근거 구절·숫자 원문 대조.
- 근거 구절이 따옴표·띄어쓰기 정도만 다르면 원문 문장으로 자동으로 맞추고(일치도 82% 이상), 없는 내용은 통과하지 못해요.
- 이 초안에 `수정:` 댓글을 달면 그때는 Claude API(약 200원)를 써요. 무료로 고치려면 Claude 대화창에서 고친 원고로 새 이슈를 만드세요.
