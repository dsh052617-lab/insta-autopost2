# 준비해 둔 대체 카드

오후 대체 카드 작업(`docs/insta_fallback.md`)이 새로 만들기 전에 여기서 먼저 꺼내 쓴다.
- 파일 이름: `<주제>-<종류>-<짧은이름>.json` (주제 economy/ai, 종류 term/history/compare)
- 내용: 이슈 본문 JSON 그대로. `"date"`는 `"TODAY"`로 두고, 쓸 때 오늘 날짜로 바꾼다.
- 한 번 쓴 카드는 `used/`로 옮긴다(같은 카드를 두 번 올리지 않는다).
- 시간이 지나면 내용이 낡는 카드(모델 비교, 최근 수치가 들어간 용어 카드)는 넣지 않는다.
